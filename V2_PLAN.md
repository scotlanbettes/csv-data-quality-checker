# CSV Data Quality Checker - Version 2

## Developer

Job Munyoki

## Goal

Upgrade the original CSV Data Quality Checker into a more advanced, production-style data quality and cleaning application.

## Planned V2 Features

### Advanced Validation

- Missing value detection
- Duplicate row detection
- Duplicate ID detection
- Data type validation
- Inconsistent data type detection
- Empty string detection
- Leading/trailing whitespace detection
- Inconsistent capitalization detection
- Outlier detection

### Data Quality Scoring

- Improved overall quality score
- Column-level quality scores
- Issue severity levels

### Data Cleaning

- Remove duplicate rows
- Handle missing values
- Trim whitespace
- Standardize text
- Remove or fix invalid values
- Download cleaned CSV

### Dashboard

- Overview tab
- Issues tab
- Column Analysis tab
- Data Cleaning tab
- Report tab

### Reporting

- Downloadable data quality report
- Summary of detected issues
- Cleaning actions performed

### Engineering

- Automated tests
- GitHub Actions CI
- Improved documentation
- Version 2 deployment
